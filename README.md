# Amazon Sales Data Analysis (Excel Project)

This project showcases an end-to-end Excel-based data analysis using Amazon's sales dataset. The project began with raw data, which was cleaned, transformed, and visualized into a dashboard — all using Microsoft Excel.

## 📂 Files Included

- `amazon original.xlsx` – The original, unprocessed dataset
- `TEAM 1 Cohort D.xlsx` – Cleaned data with insights and dashboards

## 🛠 Tools Used

- **Microsoft Excel**
  - Data Cleaning (removing duplicates, fixing formats, handling blanks)
  - Data Transformation using formulas and structured tables
  - Pivot Tables & Charts
  - Dashboard creation using slicers, conditional formatting, and layout design

## 🔍 Key Highlights

- Understanding how to clean and relate data in Excel
- Creating pivot-based summaries and interactive dashboards
- Gaining insights into sales trends, top-performing categories, and customer behavior

## 📊 Dashboard

All dashboards and insights are created within Excel without any external tools like Power BI.
